# lesson-plan

A LaTeX class for lesson plans. Clean, compact, professional built for Brazilian institutions.

## Requirements

- LuaLaTeX: the supported engine
- biber: bibliography backend

## Usage

Copy `lessonplan.cls` alongside your `.tex` file, or drop it in your TeX project. Then:

```latex
\documentclass{lessonplan}

\lpuniversity{Nome da Universidade}
\lpinstitute{Nome do Instituto}
\lpfaculty{Nome da Faculdade ou Programa}

\lpdiscipline{Nome da Disciplina}
\lptheme{Tema da Aula}
\lpdate{Data da Aula}
\lpduration{Duração da Aula}
\lpteacher{Nome do Docente}
\lplocation{Local da Aula}

\lpbibresource{main.bib}

\begin{document}

\maketitle

\section{Objetivos}
...

\lpprintbibliography

\end{document}
```

See [main.tex](main.tex) for a complete, fill-in-the-blanks template.

Compile with `latexmk -lualatex` (handles the biber pass automatically), or manually: `lualatex`, `biber`, `lualatex`, `lualatex`.

## Structure

- Title block: renders once, right after `\begin{document}`. Shows university/institute/faculty and up to three logos.
- Identificação: fixed fields (disciplina, tema, data, duração, docente, local), auto-generated by `\maketitle`. Not free text.
- Content sections: plain `\section{...}`, styled by the class. Default set: Objetivos, Conteúdo programático, Procedimentos metodológicos, Recursos didáticos, Avaliação, Referências. Add, remove, or reorder as needed.
- Running header/footer: discipline/docente in the header, data/local in the footer, on every page.

## Logos

Set any combination of `\lpuniversitylogo`, `\lpinstitutelogo`, `\lpfacultylogo` (paths to image files). The title block adapts to how many are set:

| Logos set | Layout                                  |
|-----------|------------------------------------------|
| 0         | Text only, centered                       |
| 1         | Centered above the text                   |
| 2         | Flanking the text, same line              |
| 3         | Side by side in a row, above the text     |

## Bibliography

Backed by `biblatex` + `biber`, styled per Brazilian ABNT norms (`biblatex-abnt`). Register a `.bib` file with `\lpbibresource{...}`, then call `\lpprintbibliography`.

- With citation: use `\cite{key}` in the text; only cited entries print.
- Without citation: call `\nocite{*}` before `\lpprintbibliography` to print every entry regardless of citation.
